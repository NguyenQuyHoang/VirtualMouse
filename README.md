# 🖱️ Virtual Mouse Project  

## 🛠️ Technical Stack  
- **Flask** – Web framework  
- **OpenCV** – Image processing  
- **MediaPipe** – Hand tracking  
- **PyAutoGUI** – Mouse control  

## 📥 How to Download and Setup  

### 1️⃣ Clone the Repository  
1. git clone <URL_GIT>

2. File -> Opent Folder -> VirtualMouse !important

3. python -m venv myenv

4. Windown: myenv\Scripts\activate

5. pip install flask opencv-python mediapipe numpy pyautogui flask-cors

6. run file app.py
